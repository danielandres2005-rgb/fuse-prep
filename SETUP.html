FREE SETUP / NO CODE REQUIRED

Install FUSE PREP
on your phone & Mac.

Start locally with no account. To make photos show up in Whatnot CSV exports and keep your inventory synced across devices, set up a free web address and free Supabase account.

Option A — Try it now (no accounts)

  1. Open index.html through a local web server, or open the included separate FusePrep-Open-Now.html to try it on Mac without setup.
  2. Type in listing titles, prices, and sizes; import your photos.
  3. Your edits save on this device. You can download a backup JSON anytime.

Limits: Locally saved photos are not publicly hosted. Other devices will not see them, and Whatnot can't read their bytes from a CSV.

Option B — Make the app installable (free GitHub Pages)

  1. Visit github.com/signup and create a free account, if you don't have one.
  2. Go to github.com/new. Repository name: fuse-prep. Select Public. Click Create repository.
  3. In the new repository choose uploading an existing file (or Add file → Upload files). Unzip the Fuse Prep package. Upload all app files in the fuse-prep-app folder into the root of your repository. Include index.html, app.js, core.mjs, sw.js, styles.css, SETUP.html, manifest.webmanifest, and the icon files. You don't need to upload supabase-setup.sql or README.md, but you can.
  4. Click Commit changes.
  5. Open your repository Settings → Pages. Under Build and deployment, select Deploy from a branch; set branch to main and folder to /(root). Click Save.
  6. GitHub gives you an address like https://YOURUSERNAME.github.io/fuse-prep/. Open that URL on your Mac and phone.

You now have your own online app. GitHub Pages itself does not sync your inventory or upload photos; follow the next step for that.

Option C — Turn on free photo hosting + sync (Supabase)

  1. Visit supabase.com/dashboard and create a free account.
  2. Click New project; choose your organization, name it Fuse Prep, choose a strong database password, and choose the Free plan.
  3. In Supabase open SQL Editor → New query.
  4. Open the included file supabase-setup.sql in TextEdit on your Mac. Copy all the contents into SQL Editor. Click Run. That creates your private workspace table and a public-read photo bucket where only signed-in users can upload into their own folders.
  5. In Supabase, find your project's Project URL and its publishable (or legacy anon) key under Project Settings → API or Connect (the dashboard label may change).
  6. Go back to your hosted Fuse Prep app and click ☁ Cloud sync.
  7. Open 1. Add Supabase project connection. Paste the Project URL and publishable key. Click Save connection.
  8. Type your email and a password, then click Create account. If Supabase asks you to confirm your email, do so, then click Sign in.
  9. Import photos. They are compressed before upload to reduce storage use. Tap Upload photos if automatic upload hasn't completed. The app adds the resulting public https:// links to your CSV.
  10. On your second device, visit your GitHub Pages Fuse Prep address. Enter the same Project URL and publishable key, then sign in with the same email and password. Choose to load cloud data when prompted.
Security: Only use the publishable or anon key in the app. Never use a service_role or secret key. Public photo links can be viewed by anyone who has them; this is necessary for Whatnot.

Install it like an app

iPhone

  1. Open your GitHub Pages URL in Safari.
  2. Tap the Share icon.
  3. Scroll down and tap Add to Home Screen (or choose it under share options), then Add.

Mac

  1. Open your GitHub Pages URL in Chrome.
  2. Use the Install button when shown, or Chrome's Save and share → Install page as app option (wording may vary).

How to prep 100 shirts quickly

  1. Set your batch price and press PRICE ALL.
  2. Enter Whatnot's exact Category, Sub Category, and Shipping Profile. Type Auction is preset.
  3. Type each title and tap a size button. It appends the size to the title and adds SIZE: XL (or the selected size) to the description.
  4. Use + Add photos to select 100–300 photos in a batch.
  5. Set Photos per listing to 1, 2, or 3, depending how you photographed the shirts, and press Assign photos in order. Fix any exceptions by dragging or tapping.
  6. For CSV image links, wait until the photos are uploaded to your free cloud project.
  7. Click Export CSV. Fix any flagged missing required fields. You can deliberately exclude unhosted photos and import draft listings without images.
  8. From a computer, visit whatnot.com → Seller Hub → Inventory → Import from CSV. Choose the exported file. Whatnot will create inventory drafts.

Important limitations

Free-tier quotas: Supabase's free plan currently includes 1 GB object storage and 500 MB database storage, with 5 GB egress allowances and pausing after one week of inactivity. Your workload may exceed these caps; free forever is not guaranteed. This app never asks for a paid subscription, and it cannot raise those limits. Compressing photos reduces usage.

CSV compliance: Fuse Prep exports the exact column names and order from the template you uploaded. The valid category, subcategory, shipping, type, and condition values still need to be copied from Whatnot's official Values sheet, which wasn't included in your CSV upload. Test with 1–2 items before importing 100.

Cloud conflicts: If two devices edit the same workspace simultaneously, the last cloud save can overwrite the other. Work on one device at a time, sync, and use JSON backups.

Photo backups: The JSON backup includes descriptions, slot assignments, and hosted URL references; it does not embed the original photo bytes. Photos saved only locally live in your browser's IndexedDB, and browser data clearing can delete them. Keep your original camera photos too.

CSV imports: Every Whatnot CSV import creates new drafts rather than updating existing drafts. Avoid repeatedly importing the same file unless you intend duplicates.
